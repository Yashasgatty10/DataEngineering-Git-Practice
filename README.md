# DataEngineering-Git-Practice

A collection of **Data Engineering workshop exercises and practice projects** covering Python web scraping, Docker, Docker Compose, PostgreSQL, Git, and GitHub.

This repository contains multiple independent projects completed while learning and practicing Data Engineering fundamentals.

---

## Repository Overview

The repository currently contains two main projects:

| Project | Description |
|---|---|
| `mydocker/` | Dockerized web-scraping practice using Books to Scrape |
| `python-blog-homework/` | Workshop 1 homework that scrapes Python Insider and stores the data in PostgreSQL |

The projects are kept in separate directories because they represent **different exercises and workflows**.
