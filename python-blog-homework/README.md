# Python Blog Scraper

## Workshop 1 Homework

### Aim

Scrape blog posts from [Python Insider](https://blog.python.org/) and store the scraped data in a PostgreSQL database.

The project is Dockerized using Docker Compose.

## Technologies Used

- Python 3.12
- Requests
- BeautifulSoup4
- PostgreSQL 14
- Docker
- Docker Compose
